# 本地未跟踪工作区

本仓库根目录下有一个 **不被 Git 跟踪** 的本地工作区 `qb-nas/`。它不是项目代码，也不应提交到本仓库（本仓库为公开仓库）。

## qb-nas/

| 项         | 说明                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 位置       | 仓库根目录 `qb-nas/`（与仓库同名，容易混淆）                                                                               |
| 体积       | 约 291 MB                                                                                                                  |
| 内容       | 本项目本地工作区：`作品/`、`作品空间/`、`工作文档/`、`系统文档/`、`截图/`、`经验/`，以及 `总图景.md`（项目现状与交接说明） |
| 生成物     | `.blueprint-evidence/`、`.blueprint-tmp/` 由 blueprint 工具生成，内含数千个 `.py` / `.pyc` / `.swift` 中间文件             |
| 为何不入库 | 体积大且以生成物为主；文档内含部署地址、交接事项等仅限本地内容，不适合公开仓库                                             |

## 约定

- **不要** `git add -A` 或 `git add qb-nas`：会把上述 291 MB 目录整体带进公开仓库。
- 项目需要提交的说明只放在 `docs/` 下（例如本文件），不在 `qb-nas/` 内创建 Git 内容。
- codegraph 索引通过根目录 `codegraph.json` 的 `exclude` 排除该目录，避免把数千个生成文件扫进索引。
- 若希望 `git status` 不再列出这些文件，可把 `qb-nas/` 写入根 `.gitignore`；当前尚未加入，需明确授权后再改。

## 相关文件

- `codegraph.json` — codegraph 索引范围配置（排除 `qb-nas/`）
- `总图景.md`（位于 `qb-nas/` 内，不随仓库分发）— 项目现状与交接说明

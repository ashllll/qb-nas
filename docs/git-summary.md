## 演进脉络总结

```
克隆空项目 → v3.0 架构 → Playwright→Crawl4AI → AI→本地分类
   → 成人识别 + 4K过滤 → 路径去硬编码(9轮迭代) → 爬虫性能 → 修复收尾
```

整个历史是一次**紧凑的从架构到细节的完整迭代**：

1. **先搭骨架** — v3.0 包结构重构，分层组件
2. **再换引擎** — Crawl4AI 替代 Playwright
3. **砍 AI 依赖** — 本地规则替代 MiniMax，简化部署
4. **啃硬骨头** — 花了最多时间（9 轮迭代）解决 Docker 容器内外路径映射问题，最终用 qB API 原生方案收尾
5. **性能调优** — 爬虫并发策略、缓存、批量延迟
6. **清理收尾** — 移除无用文件、导入清理
